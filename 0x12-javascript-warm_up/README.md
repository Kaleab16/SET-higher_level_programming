# JavaScript - Warm up Part 1 🚀

This project is my entry point into JavaScript. 🟨

The goal is to get comfortable with the fundamentals by building small programs, experimenting with the language, and learning how JavaScript behaves in practice.

This warm-up covers the basics I need before moving into larger JavaScript projects:

- 🧱 Variables and constants
- 🔤 Data types
- ➕ Operators
- ⚙️ Functions
- 📥 Arguments and return values
- 🔁 Loops and conditionals
- 📦 Objects and arrays
- 💻 Working with the command line
- ✨ Writing clean, executable JavaScript

I am approaching this project as a foundation rather than just a collection of exercises. The focus is on understanding the logic behind each task, writing the solutions myself, and building habits that will carry into more complex software projects.

Every task is a small step toward becoming more comfortable with JavaScript and, eventually, building things that are much bigger than these warm-ups. 🌱

**Environment:** Ubuntu 20.04 LTS 🐧  
**Runtime:** Node.js 14.x 🟢  
**Style:** Semistandard 16.x 📐
